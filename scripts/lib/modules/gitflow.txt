# incompatible with the foundation's documented default (trunk-ish / GitHub
# Flow — feature/ branches off main, rebase, squash; see .claude/rules/git.md).

# rather than universal core (same framework-grain rationale as nextjs/flutter).
# Commands only — no agents or skills. Same syntax as minimal-manifest.txt:
# one repo-relative path per line, # comments and empty lines ignored.
# Drift guard: tests/modules.bats asserts every path exists and no overlap.
