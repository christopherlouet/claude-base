Créer un pitch deck et préparer la présentation d'un projet.

## Processus de création

### 1. Comprendre le projet

#### Explorer le projet
```bash
cat README.md 2>/dev/null
cat package.json 2>/dev/null
```

#### Questions clés
- Quel problème résolvez-vous ?
- Pour qui ?
- Quelle est votre solution ?
- Pourquoi maintenant ?
- Pourquoi vous ?

### 2. Structure du pitch deck

#### Slides essentielles (10-12 slides)

```
1. Titre
2. Problème
3. Solution
4. Démo/Produit
5. Business model
6. Traction
7. Marché
8. Concurrence
9. Équipe
10. Roadmap
11. Financier (si levée)
12. Ask / Call to Action
```

### 4. Règles du pitch

#### Le pitch en 1 minute (elevator pitch)
```
[Produit] est un [catégorie]
pour [cible]
qui [bénéfice principal].

Contrairement à [alternative],
nous [différenciateur unique].

Nous avons déjà [traction]
et cherchons [demande].
```

#### Do's
- [ ] Raconter une histoire
- [ ] Être spécifique (chiffres, exemples)
- [ ] Montrer la passion
- [ ] Anticiper les questions
- [ ] Finir par un call-to-action clair

#### Don'ts
- [ ] Jargon technique
- [ ] Trop de slides (>15)
- [ ] Trop de texte par slide
- [ ] Projections irréalistes
- [ ] Ignorer la concurrence

---

IMPORTANT: Un pitch doit être compréhensible par quelqu'un qui ne connaît pas votre domaine.

YOU MUST avoir des chiffres concrets - même petits, ils crédibilisent.

NEVER mentir sur les métriques - les investisseurs vérifieront.

Think hard sur le "pourquoi maintenant" et le "pourquoi vous" - ce sont les questions clés.
