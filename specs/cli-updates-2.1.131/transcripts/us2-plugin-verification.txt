Caveat — .zip not accepted by `plugin validate`
-----------------------------------------------

Ran: `claude --bare plugin validate ./test-plugin.zip` (a valid zip of the dir
above)

Output:
  Validating plugin manifest: /tmp/cli-2131-verify/test-plugin.zip
  ✘ Found 1 error:
    ❯ json: Invalid JSON syntax: JSON Parse error: Unexpected identifier "PK"
  ✘ Validation failed

Interpretation: the `plugin validate` subcommand reads the path argument as a
JSON file, not as an archive. The "PK" identifier is the standard zip magic
number (PK\x03\x04). Asymmetry with `--plugin-dir` runtime, which DOES accept
.zip per the help text.

Recipe implication: if a user wants to validate a plugin manifest, they must
unzip first OR validate the manifest directory before zipping for distribution.
