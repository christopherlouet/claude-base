# QA Commands

> Qualite (review, securite, performance, accessibilite)

## Overview

This domain contains **16 commands** for qualite (review, securite, performance, accessibilite).

## Commands list

| Command | Description |
|----------|-------------|
| [`/qa:qa-audit`](/docs/commands/qa/qa-audit) | Complete project quality audit. Combines security, GDPR, accessibility, performance and code quality. |
| [`/qa:qa-automation`](/docs/commands/qa/qa-automation) | Set up a comprehensive test automation strategy. |
| [`/qa:qa-chrome`](/docs/commands/qa/qa-chrome) | Visual tests and browser debugging via Claude Code's Chrome integration. |
| [`/qa:qa-coverage`](/docs/commands/qa/qa-coverage) | Analyze and improve the test coverage of the code. |
| [`/qa:qa-design`](/docs/commands/qa/qa-design) | UI/UX design audit and verification of web best practices. |
| [`/qa:qa-e2e`](/docs/commands/qa/qa-e2e) | End-to-End tests with Playwright or Cypress. |
| [`/qa:qa-kaizen`](/docs/commands/qa/qa-kaizen) | Continuous improvement of code and processes with the Kaizen methodology. |
| [`/qa:qa-loop`](/docs/commands/qa/qa-loop) | Autonomous loop AUDIT (parallel) → VALIDATE → FIX → VERIFY → CHECK with stopping criteria. |
| [`/qa:qa-mobile`](/docs/commands/qa/qa-mobile) | Quality audit specific to mobile applications (Flutter, React Native). |
| [`/qa:qa-neovim`](/docs/commands/qa/qa-neovim) | Quality and performance audit of a Neovim configuration. |
| [`/qa:qa-perf`](/docs/commands/qa/qa-perf) | Performance analysis and optimization. |
| [`/qa:qa-responsive`](/docs/commands/qa/qa-responsive) | Responsive and mobile-first audit of a web application. |
| [`/qa:qa-review`](/docs/commands/qa/qa-review) | Performs a thorough and constructive code review. |
| [`/qa:qa-security`](/docs/commands/qa/qa-security) | Security audit based on OWASP Top 10. |
| [`/qa:qa-tech-debt`](/docs/commands/qa/qa-tech-debt) | Identification and prioritization of technical debt in the codebase. |
| [`/qa:wcag-audit`](/docs/commands/qa/wcag-audit) | Accessibility audit based on WCAG 2.1/2.2 and the axe-core reference. |
